# KMD Assistant -- ALDMEGA LAB

[![CI](https://github.com/petrbras17-hue/kmd-assistant/actions/workflows/ci.yml/badge.svg)](https://github.com/petrbras17-hue/kmd-assistant/actions/workflows/ci.yml)

Полная AI-платформа для инженеров-конструкторов алюминиевых светопрозрачных конструкций.
32 модуля, 40+ API эндпоинтов, AI на базе OpenRouter (Gemini), инженерные калькуляторы по ГОСТ/СП.
Автоматизирует весь цикл: от технического задания до ЧПУ-программы и акта выполненных работ.

**Разработано для:** АО "Ал Д Мега Лаб"
**Стек:** FastAPI + Tailwind CSS + Alpine.js + Three.js
**Профильные системы:** Reynaers, Schuco, Alutech, TATPROF

## Быстрый старт

### 1. Установка

```bash
# Клонирование
git clone https://github.com/petrbras17-hue/kmd-assistant.git
cd kmd-assistant

# Виртуальное окружение
python3 -m venv venv
source venv/bin/activate    # macOS/Linux
# venv\Scripts\activate     # Windows

# Зависимости
pip install fastapi uvicorn python-multipart
pip install PyMuPDF pandas openpyxl python-docx ezdxf
pip install Pillow pytesseract
```

### 2. Запуск

```bash
source venv/bin/activate
python3 webapp/server.py
```

Откройте в браузере: **http://localhost:8080**

### 3. Для OCR сканированных чертежей (опционально)

```bash
# macOS
brew install tesseract tesseract-lang

# Ubuntu/Debian
sudo apt install tesseract-ocr tesseract-ocr-rus

# Windows — скачайте с https://github.com/UB-Mannheim/tesseract/wiki
```

## Возможности (12 модулей)

### 1. Сравнение спецификаций (Спецификации)

**Что делает:** Сравнивает два XLSX-файла спецификаций и находит расхождения по артикулам и количествам.

**Как использовать:**
1. Перейдите на вкладку "Спецификации"
2. Загрузите два Excel-файла (перетащите или нажмите)
   - Файл 1: например, спецификация от проектировщика
   - Файл 2: например, спецификация от производства
3. Нажмите "Сравнить"

**Результат:**
- Совпадающие позиции (артикул + количество)
- Расхождения по количеству (например, заказ 100 шт, а в спецификации 95)
- Позиции, отсутствующие в одном из файлов
- Скачивание отчёта в XLSX

**Форматы XLSX:** Автоматически определяет 3 типа:
- Столбцы "Артикул" + "Количество"
- Столбцы "Код" + "Кол-во"
- Первый числовой столбец как артикул, второй как количество

---

### 2. Проверка PDF (Проверка PDF)

**Что делает:** Извлекает текст из PDF-файла КМД и проверяет его полноту.

**Как использовать:**
1. Загрузите PDF-файл чертежа
2. Нажмите "Проверить PDF"

**Результат:**
- Количество страниц
- Извлечённый текст (для проверки, что PDF не является чистым сканом)
- Предупреждение, если текст не извлекается (нужен OCR)

---

### 3. Парсинг КМД (Парсинг КМД)

**Что делает:** Извлекает структурированные данные из PDF чертежа КМД -- позиции, артикулы, количества, размеры.

**Как использовать:**
1. Загрузите PDF-файл КМД
2. Нажмите "Парсить КМД"

**Что извлекается:**
- **Позиции:** Поз.О-1, Поз.БФ1, Поз.В-3 и т.д.
- **Артикулы:** 7-значные номера профилей (4080102, 1809698 и др.)
- **Количества:** из записей "Количество: N"
- **Размеры:** все числовые значения 50-5000 мм

**Пример:** Из КМД "Остров 2 Окна" извлекается 37 позиций, 18 артикулов, 1599 изделий.

---

### 4. Кросс-валидация (Кросс-валидация)

**Что делает:** Сверяет артикулы из PDF-чертежа с Excel-спецификацией. Находит расхождения между тем, что нарисовано, и тем, что заказано.

**Как использовать:**
1. Загрузите PDF-чертёж (например, КМД Остров 2)
2. Загрузите XLSX-спецификацию (например, заказ на профили)
3. Нажмите "Сверить"

**Результат:**
- Совпадающие артикулы (есть и в чертеже, и в спецификации)
- Только в чертеже (забыли заказать)
- Только в спецификации (лишние позиции в заказе)

---

### 5. Сравнение версий PDF (Сравнение PDF)

**Что делает:** Сравнивает две версии PDF-документа и показывает разницу (что добавлено, удалено, изменено).

**Как использовать:**
1. Загрузите "старую" версию PDF
2. Загрузите "новую" версию PDF
3. Нажмите "Сравнить версии"

**Результат:**
- Процент схожести текста
- Удалённые строки (красные)
- Добавленные строки (зелёные)
- Подробный diff

**Важно:** Работает только с текстовыми PDF. Сканы без OCR-слоя покажут 0% схожести.

---

### 6. Генерация спецификации (Генерация)

**Что делает:** Автоматически создаёт Excel-спецификацию из PDF-чертежа КМД.

**Как использовать:**
1. Загрузите PDF-файл КМД
2. Нажмите "Сгенерировать спецификацию"
3. Скачайте готовый XLSX-файл

**Что попадает в спецификацию:**
- Позиция (Поз.О-1, Поз.БФ1...)
- Артикул профиля (7-значный код)
- Количество изделий
- Сформатированный файл со стилями (жирные заголовки, авто-ширина столбцов)

---

### 7. Пакетная обработка (Пакетная)

**Что делает:** Анализирует ZIP-архив с несколькими файлами проекта (PDF + DXF) за один раз.

**Как использовать:**
1. Соберите все файлы проекта в ZIP-архив
2. Загрузите архив
3. Нажмите "Обработать архив"

**Результат по каждому файлу:**
- PDF: извлечённые позиции, артикулы, оценка по чек-листу
- DXF: слои, тексты, блоки, размеры
- Сводная статистика: средняя оценка, общее количество позиций и артикулов

---

### 8. Чек-лист КМД (Чек-лист)

**Что делает:** Автоматическая проверка комплектности и качества КМД по 7 категориям, специально настроенная для алюминиевых светопрозрачных конструкций.

**Как использовать:**
1. Загрузите PDF-файл КМД
2. Нажмите "Проверить по чек-листу"

**Категории проверок (31 проверка):**

| Категория | Что проверяется | Вес |
|---|---|---|
| **Титульный лист и реквизиты** | Объект, заказчик, договор, исполнитель, тип конструкций, дата | Критично |
| **Пояснительная записка** | Наличие ПЗ, состав документации, указания по монтажу, профильная система | Критично |
| **Чертежи изделий** | Позиции, количества, высота ручки, размеры, виды, сечения | Критично |
| **Артикулы и комплектующие** | Артикулы профилей (7-значные), крепёж, уплотнители | Критично |
| **Узлы и примыкания** | Узлы сборки, герметизация (ПСУЛ, вилатерм, силикон), импосты | Важно |
| **Полнота и консистентность** | Объём документации, покрытие позиций количествами, формат позиций | Важно |
| **Оформление документации** | Маркировка КМД, тип документации, подписи | Рекомендовано |

**Система оценки:**
- Взвешенная оценка: критические проверки (вес 3) влияют сильнее рекомендуемых (вес 1)
- Проверки основаны на ГОСТ 21.502-2016, СП 426.1325800.2018, ГОСТ 21519-2022
- Реальный КМД АЛЬДМЕГА ЛАБ получает 98%+ (настроено на реальную документацию)

**Нормативные документы:**
- ГОСТ 21.502-2016 -- Правила выполнения рабочей документации металлических конструкций
- СП 426.1325800.2018 -- Конструкции фасадные светопрозрачные
- ГОСТ 21519-2022 -- Блоки оконные из алюминиевых профилей
- СП 128.13330.2016 -- Алюминиевые конструкции

### 9. Подбор профильной системы (Подбор системы)

**Что делает:** AI-рекомендация оптимальной профильной системы по параметрам проекта. Учитывает ветровую нагрузку, теплоизоляцию, размеры, бюджет.

**Как использовать:**
1. Выберите тип конструкции: окна, витражи, фасады, двери, раздвижные
2. Укажите размеры (ширина x высота в мм)
3. Укажите этажность здания и ветровой район (I-VII по СП 20.13330)
4. Выберите требования: теплоизоляция, звукоизоляция, огнестойкость
5. Выберите бюджет: эконом / стандарт / премиум
6. Нажмите "Подобрать систему"

**Результат:**
- Ранжированный список систем с оценкой 0-100 баллов
- Для каждой системы: Uf (теплопередача), макс. стеклопакет, макс. вес створки
- Плюсы и минусы каждой системы
- Обоснование выбора
- Предупреждения (высотность, ветровая нагрузка)

**База профильных систем (18 систем):**

| Производитель | Системы |
|---|---|
| **Reynaers** | MasterLine 8, MasterLine 8 HI, ConceptWall 50, ConceptWall 60, Hi-Finity, CS 86-HI |
| **Schuco** | AWS 75.SI+, AWS 90.SI+, FWS 50+.SI, FWS 60+.SI, ASS 77 PD.HI, ADS 90.SI |
| **Alutech** | ALT W72, ALT F50, ALT F50 NL, ALT SL160, ALT C48 |
| **TATPROF** | TPT 65A, TPT 47A |

**Алгоритм скоринга (6 критериев):**
- Теплоизоляция (Uf vs требования) -- 25%
- Макс. размеры vs запрашиваемые -- 20%
- Ветровая нагрузка (этаж + регион по СП 20.13330) -- 20%
- Соответствие бюджету -- 15%
- Толщина стеклопакета -- 10%
- Огнестойкость -- 10%

### 10. Оптимизация раскроя профилей (Раскрой)

**Что делает:** Рассчитывает оптимальный план раскроя алюминиевых профилей для минимизации отходов. Экономит 10-25% материала по сравнению с ручной нарезкой.

**Как использовать (ручной ввод):**
1. Укажите длину заготовки (стандарт: 6500 мм для алюминиевых профилей)
2. Укажите ширину реза пилы (обычно 5 мм)
3. Укажите минимальный полезный остаток (обычно 50 мм)
4. Добавьте необходимые нарезки: артикул, длина (мм), количество
5. Нажмите "Рассчитать раскрой"

**Как использовать (из PDF):**
1. Переключите режим на "Из PDF"
2. Загрузите PDF-файл КМД
3. Система автоматически извлечёт артикулы и размеры
4. Нажмите "Автораскрой из КМД"

**Результат:**
- Количество заготовок (штанг) для закупки
- Процент отходов (цель: менее 10%)
- Экономия по сравнению с наивным подходом
- **Визуальная карта раскроя:** каждая штанга показана горизонтальной полосой с цветными сегментами нарезок
- Цветовая индикация утилизации: зелёный (>90%), жёлтый (70-90%), красный (<70%)
- Сводка по артикулам: общее количество нарезок и суммарная длина
- Детальный план по каждой штанге

**Алгоритм:**
- First Fit Decreasing (FFD) -- проверенный алгоритм bin-packing
- Сортировка нарезок от длинных к коротким
- Учёт ширины реза пилы между деталями
- Оптимизационный проход: перераспределение деталей между штангами для снижения отходов

**Пример:**
- Вход: 10 шт x 1200 мм, 20 шт x 830 мм, 15 шт x 536 мм (артикулы 4080102, 4080183)
- Результат: 6 штанг по 6500 мм, отходы 5.6%, экономия 14.3% vs наивный подход

### 11. 3D-просмотр конструкций (3D Просмотр)

**Что делает:** Генерирует интерактивную 3D-модель алюминиевой конструкции (окно, витраж, дверь, фасад) прямо в браузере.

**Как использовать (ручной ввод):**
1. Выберите тип конструкции
2. Укажите размеры: ширина, высота, глубина профиля (мм)
3. Укажите формулу стеклопакета (например, 4-16-4-16-4)
4. Настройте секции: глухое, поворотно-откидное, поворотное
5. Выберите цвета (снаружи / изнутри)
6. Нажмите "Построить 3D"

**Как использовать (из PDF):**
1. Переключите режим на "Из PDF"
2. Загрузите PDF-файл КМД
3. Система извлечёт размеры и параметры автоматически

**Управление 3D-сценой:**
- Вращение: зажмите левую кнопку мыши и двигайте
- Масштаб: колёсико мыши
- Перемещение: зажмите правую кнопку мыши
- Кнопки: повернуть влево/вправо, сбросить вид
- Переключатели: каркасный режим, размерные линии
- Экспорт в PNG

**Что отображается:**
- Алюминиевый профиль с металлическим материалом (metalness 0.8, roughness 0.3)
- Стеклопакеты с полупрозрачным стеклом (transmission 0.9)
- Импосты (вертикальные/горизонтальные разделители)
- Ручки на открывающихся створках
- Индикаторы типа открывания
- Размерные линии с подписями в мм

### 12. Дашборд (Дашборд)

**Что делает:** Сводная статистика по всем операциям за текущую сессию.

**Отображает:**
- Общее количество операций
- Счётчики по каждому типу: сравнения, проверки, парсинг, чек-листы и т.д.
- Журнал последних операций: время, тип, файл, результат

## Структура проекта

```
KMD/
  webapp/
    server.py        # FastAPI бэкенд (18 эндпоинтов, ~3100 строк)
    index.html       # Фронтенд (12 табов, ~2500 строк)
    uploads/         # Временные загрузки (автоочистка)
    results/         # Сгенерированные файлы для скачивания
  tools/
    compare_orders.py   # Сравнение Excel-спецификаций
    pdf_tools.py        # Извлечение текста и таблиц из PDF
    docx_tools.py       # Чтение Word-документов
    dxf_tools.py        # Парсинг DXF/AutoCAD чертежей
    ocr_tools.py        # OCR распознавание сканов
    excel_tools.py      # Работа с Excel
    kmd_checker.py      # Логика проверок КМД
    requirements.txt    # Зависимости Python
```
